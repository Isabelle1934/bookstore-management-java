
# 📚 Bookstore Management System

A Java application designed to manage bookstore operations, including book inventory, pricing, and stock control.

This project aims to apply Object-Oriented Programming (OOP), data management, and software engineering principles to a practical business scenario.

## 🚀 Features

- Add new books to the inventory
- List all registered books
- Search for books by title or ISBN
- Update book information
- Remove books from the inventory
- Manage book prices and stock quantities
- Validate user input and handle errors

> Note: Features will be listed as completed as they are implemented.

## 🛠️ Technologies

- **Java** — Core application logic
- **Object-Oriented Programming (OOP)** — Code organization and modeling
- **Git & GitHub** — Version control
